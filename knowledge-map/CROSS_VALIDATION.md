## 一、验证方法：分层交叉验证

1225 条知识点不可能逐条人工搜索，采用**四层递进**的方法，全量与抽样结合：

| 层次 | 覆盖范围 | 方法 | 结果 |
|---|---|---|---|
| L1 结构校验 | 100%（1225 条） | `validate.py` + `build_volumes.py`：字段、ID、引用、领域、难度-认知一致性 | 0 错误 0 警告 |
| L2 机器交叉比对 | 100%（1225 条） | `cross_validate.py`：逐条比对课标领域/主题/学段、课标调整点、去小学化、教材版本 | 0 错误 0 警告 |
| L3 内容事实抽样 | 分层抽样 156 条 | 按学科×学段抽取高风险事实点（古诗文、名著、数学定义、英语语法），联网逐条核对 | 见第三、四节 |
| L4 问题点定向深查 | 全部命中项 | 对 L2/L3 发现的每条问题，多来源交叉确认后再修正 | 全部闭环 |

**权威性保障**：L3/L4 的每个结论都基于**多个独立权威来源**交叉印证，单一来源（如个别自媒体）不作为定论依据。

### 3.2 数学领域/主题（15 处课标归属偏差）

## 五、残余风险（如实说明）

1. **抽样边界**：L3 事实深查覆盖 156 条高风险点，其余约 1000 条常规知识点依赖 L1/L2 的机器规则校验与编写时的课标对齐，未逐条联网核对。常规概念（如加减法、字形、日常词汇）事实风险极低。
2. **教材版本并行**：2024 新版教材正逐年级铺开，新旧版本并存数年。本地图采用"新旧都保留 + source 标注差异"策略，使用者需按所在年级实际教材版本判断。
3. **描述性和目标性字段**：`objective`（学习目标）、`common_mistakes`（易错点）、`suggested_types`（建议题型）属教学性描述，无唯一"标准答案"，验证聚焦可客观判定的事实与归属。
4. **课标非穷举**：课标规定的是内容范围与学段要求，不逐条列出所有知识点；知识点的具体颗粒度与教材单元编排是合理细化，验证以"不超纲、不违规、归属正确"为准。

## 六、如何复现验证

```bash
# L1 结构校验
python3 knowledge-map/tools/build_volumes.py --dry-run
python3 knowledge-map/tools/validate.py

# L2 内容级交叉比对（本报告新增，规则固化）
python3 knowledge-map/tools/cross_validate.py
python3 knowledge-map/tools/cross_validate.py --json   # 机器可读
```

`cross_validate.py` 把本次验证的规则（课标领域调整、学段主题、去小学化、教材版本、难度-认知一致性等）固化为代码，后续任何修改都会自动重新校验，防止回退。
