# K12 题库工厂

> 仓库标识：`k12-question-bank` · 品牌名称：**K12 题库工厂**（macOS 桌面应用与项目展示名统一）

![Python](https://img.shields.io/badge/Python-3.9%2B-blue)
![License](https://img.shields.io/badge/License-MIT-green)
![进度](https://img.shields.io/badge/知识点地图-63%2F63%20%C2%B7%201225%20%E7%9F%A5%E8%AF%86%E7%82%B9-brightgreen)

> 一套**完全自研、配置驱动、可复用**的 K12 选择题生产流水线：依据 2022 版国家课程标准独立梳理知识点地图，再用「模板 + LLM」双引擎批量生成、质检、导出。
> 零第三方依赖（Python 3.9+ 开箱即用），不依赖任何外部项目的数据或代码。

## 项目定位

本项目从零开始构建，目标是工程化地生产大规模、高质量、结构化的 K12 选择题。核心理念是**源头治理**：先把知识点按权威课标梳理干净、结构化，再用代码管道批量出题——而不是逐题手工堆砌。

整个系统由两层构成：

1. **知识点地图（`knowledge-map/`）**：覆盖幼儿园 / 小学 / 初中 × 语文 / 数学 / 英语，共 63 册，每条知识点带课标领域、学习目标、难度、认知层级、前置关系、易错点、权威来源等 15 个字段。这是全项目唯一的知识点数据源。
2. **生成管道（`src/` + `scripts/`）**：读取知识点地图，用双引擎出题，经质量门禁校验后入库，导出为多种格式。

## 核心设计

| 特性 | 说明 |
|---|---|
| **知识点地图先行** | 63 册 / 1225 个知识点（幼儿园 9 + 小学 36 + 初中 18）已全部完成，依据国家课标独立梳理 |
| **双引擎 + 母题变体** | 规则类科目（数学/英语/语文基础）走模板引擎，成本≈0；语义类走 LLM 生成母题，程序化扩展 1→8，把 API 调用压到 1/8 |
| **确定性 ID** | `id = sha256(topic_id + variant + seed)`，重跑幂等，断点续传不重复扣费 |
| **质量门禁** | 结构校验 → 答案一致性 → 语义去重（字符 n-gram Jaccard）→ 难度校准 → 抽检 |
| **配置驱动** | 年级、科目、配额、难度分布、模型、并发、导出格式全在 `config/config.yaml` |
| **可插拔** | 知识点源、生成引擎、LLM provider、导出器均为独立模块 |

## 快速开始

```bash
# 1. 查看进度、领取下一册梳理任务
python3 knowledge-map/tools/progress.py --next 5

# 2. 生成某册的梳理提示词，交给 AI 梳理并写入 volumes/
python3 knowledge-map/tools/progress.py --prompt primary-g2-s1-math

# 3. 校验 → 合并 → 生成题目（端到端）
python3 knowledge-map/tools/validate.py
python3 knowledge-map/tools/merge.py
python3 scripts/run_from_map.py --try-run          # 试跑：仅模板引擎，无需 API key
python3 scripts/run_from_map.py --per-topic 24 --subject math   # 按科目生成

# 4. 全量生成（语义类题目需配 LLM key）
export DEEPSEEK_API_KEY=sk-xxxx
python3 scripts/run_full.py --target 100000 --resume

# 5. 题库质量验证
python3 scripts/verify.py
```

> **注意**：LLM key 从环境变量读取，绝不落盘。provider 按 OpenAI 兼容格式编写，换 Qwen / 豆包只改 `base_url` 与 `model`。

## 知识点体系

依据 2022 版义务教育课程标准（已联网核准）：

- **数学**：数与代数 / 图形与几何 / 统计与概率 / 综合与实践
- **语文**：六大学习任务群（语言文字积累与梳理 / 实用性阅读与交流 / 文学阅读与创意表达 / 思辨性阅读与表达 / 整本书阅读 / 跨学科学习）
- **英语**：六要素（主题 / 语篇 / 语言知识 / 文化知识 / 语言技能 / 学习策略）× 三主题范畴
- **学段**：S1(1-2年级) / S2(3-4) / S3(5-6) / S4(7-9)
- **幼儿园**：《3-6岁儿童学习与发展指南》五大领域（健康 / 语言 / 社会 / 科学 / 艺术）

单条知识点含 15 个字段，详见 [SCHEMA.md](knowledge-map/SCHEMA.md)。逐册梳理工作流见 [knowledge-map/README.md](knowledge-map/README.md)。

### 内容感知型模板生成器（v2，已实现）

旧模板引擎用硬编码词表出题（成语只有 4 个、拼音只有 5 个），理论上限约 995 道不重复题。
v2 的 `src/generators/content_aware.py` 改为**读取每个知识点自身内容**命题：

- 把 `explanation` 拆成 concept（具体做法/事实）与 mistakes（`易错点：` 之后的典型误区）
- **v2.1 重大调整：移除「领域归类 / 目标匹配 / 前置知识」等元数据题型**——那些题把知识点名当题干、考它的档案字段，不是考学习内容
- 题干围绕 `objective`（考核要求）设置情境，选项全部是**内容陈述**：
  - 要点判断：concept 的具体做法为正确项，典型误区 + 同学科同领域要点为干扰项
  - 误区识别：典型误区为答案，正确做法为干扰项
  - 术语填空：把 concept 含「关键术语」的原句挖空，术语为答案（干扰项取同学科术语）
- 每类配 6 套句子结构不同的问法模板，穿越 quality 的字符 n-gram 去重门禁
- 数学运算类知识点额外走参数化数值题（按年级限制运算种类，幼儿园严格去小学化不出算式）
- 原本路由到 LLM 的语义类知识点，在无 API key 时也能用它出有意义的题

实测容量（v2.1 内容题策略）：单点数学约 10 题、语文约 9 题、英语约 8 题；
全库估算约 **1.1 万道不重复题**，仍是旧引擎（约 995 题）的 10 倍以上。
v2.1 移除元数据题型后容量比 v2.0（约 1.3 万）略降，这是主动的质量取舍——宁可少出，不出把知识点当档案考的题。
为保证质量，初中数学的抽象符号运算、幼儿园的算式训练都主动放弃数值题——同样宁缺毋滥。默认已启用（`config.yaml: template.content_aware: true`），
设 `false` 可回退旧引擎做对比。配套把去重门禁改为按 n-gram 数量分桶比对（判定结果与原全表比对 0 差异），
避免全库数万题时的 O(n²) 卡顿。可用 `python3 scripts/verify_content_aware.py` 一键验证生成器正确性。

> 距 10 万题仍需 LLM 引擎补量：内容感知的问法模板终究有限，语义类题目（阅读、作文、
> 古诗赏析）需要 LLM 保证质量。

### 大模型出题提示词（当前主推路径）

模板引擎的固有局限是题干结构有限、情境单薄。桌面 app v2.0 起改为**提示词驱动**：
在「AI 提示词」模块勾选知识点后生成一份可直接粘贴到 DeepSeek / 元宝 / ChatGPT 的指令
（`desktop/src/prompt.py`），包含：

- 完整知识点档案（学段、年级、考核要求、核心概念、易错点、难度、认知层级、前置、来源）
- 命题规则，**明确禁止「知识点归入哪个领域」这类档案题**，要求情境化题干与同质干扰项
- **年级红线**：明确要求「题目禁止超出当前选择年级的水平」，按各知识点所属学段年级给出具体禁区（如幼儿园禁算式、低年级禁多步运算、初中禁高中内容）
- **难度分布**：按四级占比用最大余数法换算成各难度题数，提示词写明每级各出几题
- **题目来源**：每题必须带 `topic_id` / `topic_name`，标明来源于哪个知识点，便于入库溯源
- 严格 JSON 输出 Schema（来源 / 题干 / 选项 / 答案 / 解析 / 难度 / 认知层级）
- 按学科匹配的 few-shot 示例

支持单选、多选、全选；每知识点题数可选 1/3/5/10/15/20/50/100 或自定义任意正整数，难度以「容易 / 中等 / 较难 / 难」四档显示，
可用预设（基础为主 / 均衡 / 进阶 / 挑战）或自定义四级百分比，实时显示换算后的各档题数。
筛选栏学段 / 科目 / 年级默认「全部」且学段与年级联动。可在线微调文本、一键复制、导出 `.txt` / `.md`。
本地模板引擎保留在「工具 → 本地模板引擎（旧）」仅供对比。

## macOS 桌面管理台

不写网页，做成双击即开的原生 macOS 桌面窗口（Python 标准库 + 系统 Tcl/Tk，零第三方依赖、无需 Xcode）。

```bash
python3 desktop/build_app.py      # 生成 desktop/K12 题库工厂.app（只需一次）
open "desktop/K12 题库工厂.app"   # 或直接双击
```

功能：

v3.0 起界面分为两个标签页，互不干扰（v3.1 统一品牌为「K12 题库工厂」并换用项目 Logo 图标；v3.2 优化知识点勾选与排序交互）：

**模块一 · 知识点管理**

- **浏览**：左侧按 学段 → 科目 → 年级 → 册 展开 63 册，中间表格列出知识点，下方显示 15 个字段的完整详情
- **筛选**：关键词全文搜索 + 难度（容易/中等/较难/难）/ 认知层级 / 引擎过滤，默认「全部」，点列头排序
- **管理**：新增 / 编辑 / 删除知识点，改动直接写入 `knowledge-map/volumes/`（下游出题实际消费的数据）
- **安全**：每次写操作自动备份到 `desktop/backups/`、记入 `desktop/changelog.jsonl`，「撤销」可恢复
- **校验 / 导出**：一键跑三套校验；当前结果导出 CSV / JSON

**模块二 · AI 提示词（主推）**

- **筛选**：学段 / 科目 / 年级三个下拉默认「全部」；选学段后年级联动收窄（选小学只列 1—6 年级，不再显示 7/8/9 年级）。所有下拉单击展开、单击选项即选中
- **列表**：含学科、认知层级列，难度以「容易 / 中等 / 较难 / 难」文字显示；大号勾选框，点任意行即可勾选（整行变蓝），Shift + 点击可连选区间，点「选」表头按已选/未选排序；另有「全选当前」「清空选择」「反选」
- **参数**：每知识点题数可选 1/3/5/10/15/20/50/100 或「自定义」任意正整数；难度用文字四档，可用预设或四级自定义百分比，实时显示按题数换算的各档题数
- **生成**：勾 1 个出单点提示词，勾多个出批量提示词；含完整档案、年级红线、难度分布、来源字段、JSON Schema 与示例
- **使用**：文本框可微调，「复制全部」粘贴到 DeepSeek / 元宝 / ChatGPT，或导出 `.txt` / `.md`
- **本地模板出题（旧）**：收在「工具 → 本地模板引擎」，用固定模板现场出题，仅作效果对比


> 注意：`volumes/` 是 `data/*.py` 经 `build_volumes.py` 生成的产物。桌面端的改动若要永久固化，需同步回 `knowledge-map/data/` 对应源文件，再重新生成；这一约束在 app 的「使用说明」里也有提示。

也可直接运行源码：`python3 desktop/src/app.py`。
